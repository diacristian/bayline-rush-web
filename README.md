# Bayline Rush - Browser Edition

This repository contains the generated WebGL build of **Bayline Rush**.

Play: https://diacristian.github.io/bayline-rush-web/

The Unity source project and build pipeline are kept in a private repository. This public repository contains only the browser build needed to serve GitHub Pages. Bayline Rush is an original cartoon delivery game; no GTA2 code, maps, textures, audio, names, missions, or other assets are included.
